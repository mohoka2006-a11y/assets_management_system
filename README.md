# Asset Management System
## Database Project – Phase 1

### Project Overview
This project focuses on designing and implementing a relational database for an Asset Management System using Microsoft SQL Server.

The system is designed to help an organization manage its assets, categories, locations, employees, assignments, maintenance activities, and asset disposals.

### Project Objectives
- Design a structured relational database.
- Implement tables and relationships.
- Apply primary keys and foreign keys.
- Apply UNIQUE, CHECK, DEFAULT, and NOT NULL constraints.
- Create an Entity Relationship Diagram (ERD).
- Create a Relational Mapping Diagram.
- Distribute tasks among six team members.
- Test the database and its constraints.

### Database Tables
1. Categories
2. Locations
3. Employees
4. Assets
5. AssetAssignments
6. Maintenance
7. Disposals
